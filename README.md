# Squarespace Shape Motion Paths

Move Squarespace **shape blocks** along custom paths with GSAP's
[MotionPathPlugin](https://gsap.com/docs/v3/Plugins/MotionPathPlugin/), and draw and tune those paths
right on the page with [MotionPathHelper](https://gsap.com/docs/v3/Plugins/MotionPathHelper/) and a
settings panel.

Everything ships as one paste-in snippet for **Settings → Advanced → Code Injection → Footer**.

## Local testing

```bash
python3 build-test-page.py
```

```bash
python3 -m http.server 8765
```

Then open:
- <http://localhost:8765/svg-test-page-motionpath.html>: the page as a **visitor** sees it (animation
  only). Add `?mph` to force the editor.
- <http://localhost:8765/sim/config/>: the page inside a **simulated Squarespace editor**. The editor
  panel appears. **Edit** toggles Edit mode and **Phone view** toggles the device view, the way
  Squarespace does.

Serve the page over HTTP instead of opening it with `file://`. Squarespace uses protocol-relative
script URLs (`//assets.squarespace.com/...`) that fail from `file://`. Console errors about
`ChunkLoadError`, `UserAccountLink` or `floating-cart` are Squarespace chunks that can't load from
localhost. They have nothing to do with the snippet.

## Installing on Squarespace

1. Paste all of `motionpath-helper-snippet.html` into **Code Injection → Footer**.
2. Keep **one** `gsap.min.js` on the page. The snippet loads GSAP 3.14.1, so delete any other GSAP
   line and put this snippet **above** other code that uses GSAP (e.g. the image trail plugin).
3. All GSAP files must share a version (core and plugins are all `@3.14.1` now).

## Squarespace editor behavior

- **Edit mode:** while you're editing the page in Squarespace, the animation stops and the shape
  sits in its normal spot, so it can be dragged and resized. It restarts when you exit Edit mode, and
  unsaved path edits are kept.
- **Off on phones by default:** unless `mobile: true` (the panel's "Run on mobile" checkbox), the
  shape stays still on phones. The editor's mobile view counts as a phone, and so does a live-site
  window 767px wide or less. Switching view or resizing past the breakpoint starts or stops it.
- **Editor only for you:** the path editor and settings panel only appear when `SHOW_EDITOR = true`
  **and** the page is open inside the Squarespace editor, or you're logged in. Visitors never see it.
  Add `?mph` to the URL to force it anywhere.

## Editing a path (dev mode)

Open the page in the Squarespace editor (not in Edit mode) with `SHOW_EDITOR = true`. The page shows
the editable path plus a settings panel in the top-right.

| Action | How |
|---|---|
| Move a point / bend a curve | Drag anchors / handles |
| Add a point | **Option/Alt-click** the path |
| Delete a point | Click it, then **Delete/Backspace** |
| Toggle smooth ↔ corner | Option/Alt-click a point |
| Bend one side only | Option/Alt-drag a handle |
| Select multiple / all | Shift-click / Cmd/Ctrl+A |
| Undo | Cmd/Ctrl+Z |

Then click **Copy code**, paste the result over the `var CONFIG = {...};` block in the snippet, and
set `SHOW_EDITOR = false` when you're done.

## CONFIG reference

| Key | Values | Meaning |
|---|---|---|
| `block` | `"block-…"` | ID of the shape block (element matching `[data-sqsp-block="shape"]`) |
| `path` | SVG path string | Pixels. `M0,0` = the block's normal spot in the layout |
| `duration` | seconds | One trip along the path |
| `delay` | seconds | Wait before the first run |
| `ease` | GSAP ease | e.g. `"none"`, `"power2.inOut"`, `"back.out(1.7)"` |
| `playback` | `"loop"` / `"yoyo"` / `"once"` | Restart, back and forth, or play once |
| `repeatDelay` | seconds | Pause between loops |
| `start`, `end` | 0–1 | Portion of the path to travel |
| `home` | `"start"` / `"end"` | Which end of the path is the block's layout spot. `"end"` = shape flies **into** place |
| `autoRotate` | bool | Face the direction of travel |
| `rotateOffset` | degrees | Extra rotation when auto-rotating |
| `anchor` | `"x% y%"` | Point on the shape that rides the path and acts as the rotation pivot |
| `mobile` | bool (default `false`) | `false` = the shape stays still on phones. `true` = same animation on phones |

## How it works

- Code waits for `DOMContentLoaded` before touching the page. A `MutationObserver` on `<body>`'s
  class stops and starts everything when Edit mode (`sqs-edit-mode-active` / `sqs-is-page-editing`)
  toggles, or when the device view changes (`sqs-device-view-desktop` / `sqs-device-view-phone` in the
  editor, a 767px media query on the live site). Each restart also rebuilds the editor overlay.
- The editor shows when the page runs inside a same-origin parent on a `/config` path (or with
  `#sqs-site-frame`), or when `<html>` has `data-authenticated-account`.
- `window.shapeMotionPath` exposes `start()`, `stop()`, `isEditing()` and `wantEditor()` for
  debugging.
- The editor waits for window `load`,
  because MotionPathHelper pins its overlay to the block's page position when it's created, and images
  and fonts shift the layout.
- The tween animates the shape block (`.sqs-block`) with `x`/`y` transforms, so the path is relative to
  where Squarespace placed the block.
- **Anchor point** sets `transformOrigin` and offsets the editor overlay by the same amount. With
  plain x/y motion, the anchor point therefore rides exactly on the drawn line.
- `home: "end"` swaps `start` and `end` (MotionPathPlugin supports travelling a path backwards).
- MotionPathHelper forces its tween to repeat while editing, so a "once" animation loops in the
  preview and plays once for real.

## Known limitations

- Paths are in pixels, so they don't scale across breakpoints, and the mobile layout places blocks
  differently. That's why mobile is off by default. With `mobile: true`, phones currently get the
  desktop settings.
- The editor overlay doesn't follow window resizes. Reload after resizing.
- With auto-rotate on, the shape ends at the path's final angle. Flatten the last segment or use
  `rotateOffset` to land upright.
- Sections may clip shapes that travel outside them. Add `overflow: visible` to the section if needed.
- Handles one shape per snippet for now.
